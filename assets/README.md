# Assets Folder

## Required Files

### 1. Girlfriend's Photo
**Location:** `images/girlfriend-photo.jpg`

- Add a beautiful photo of your girlfriend here
- Recommended size: 500x500px or larger
- Supported formats: .jpg, .jpeg, .png
- The photo will be displayed in a circular frame on the splash screen

### 2. Background Music (Optional)
**Location:** `audio/background-music.mp3`

- Add a romantic background music file
- Recommended: Soft, instrumental music
- Format: .mp3
- Keep file size reasonable (under 5MB recommended)
- Make sure you have rights to use the music

## Finding Royalty-Free Music

Good sources for free music:
- YouTube Audio Library
- Free Music Archive
- Incompetech
- Bensound

## Image Tips

For best results:
- Use a high-quality, well-lit photo
- Center your girlfriend's face in the photo
- Avoid busy backgrounds
- Square aspect ratio works best
- File size: Keep under 1MB for faster loading

---

**Note:** These files are required for the app to work properly. The app will show errors if the girlfriend photo is missing.
